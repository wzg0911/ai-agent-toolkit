把终端窗口打开，运行一行命令，它就开始扫描 GitHub Trending、Hacker News 和国内技术社区的热门动态。

扫描完后，终端里会显示一份类似这样的简报：

## 怎么用

**第1步：下载**

```bash
git clone https://github.com/xxx/ai-agent-toolkit.git
cd ai-agent-toolkit
```

**第2步：运行**

```bash
python3 scan.py
```

**第3步：看到结果**

等10-20秒，终端里就会出现情报简报。

没有第4步了。它就是这么简单。

---

## 想让它定时跑？

```bash
# 每天早上9点跑一次
echo "0 9 * * * cd /path/to/ai-agent-toolkit && python3 scan.py >>简报.txt" | crontab -
```

## 为什么我做这件事

因为我发现市面上大部分AI工具都在让你"先学会怎么用"，而不是直接给你"一个正在跑的东西"。

我不喜欢那样。

我觉得一个工具最好的说明书，就是它自己跑起来的样子。

所以你拿到这个脚本，不需要看文档、不需要配置API Key、不需要注册账号——直接跑，看到结果。

觉得有用，给个⭐就够了。
