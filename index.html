一个值得注意的结构

项目客户数MRR单客均价

OpenAlternative（卖铲子）23$5,986$260

客户数差 13.6 倍，收入只差 1.5 倍。

这说明存在一种"低客数 · 高客单"的结构：不需要百万流量、不需要爆款、不需要投流。对单人来说，这条路比追流量更现实。

收录标准

  1. 有收入数字——具体金额 + 时间范围。不接受"月入过万"这类无锚点表述。
  2. 能追溯到证据——必须给出可点开的链接。搜索摘要不算证据。
  3. 证据等级明确——A/B/C/D 四级，逐条标注。
  4. 可被复刻——说明：需不需要本金、需不需要账号、几人可做。

不接受：卖课引流文、只有截图无第三方验证的收入、无法追溯身份的数据、任何承诺收益的内容。

反面证据（同样重要）

开源 ≠ 收入。这些案例必须一起看：

  • 独立开发者蓝源：5年折腾 + 开源简历工具 1.5k star → 总收入仅几千元；其自建导航站自述"你变不了现……产品做死了"。
  • WeHalo：1.3k star → 累计打赏 ¥540。
  • LeaferJS（万超）：一人五年开源、创造 2000 万价值 → 负债 80 万。
  • V2EX 11年副业全账本：逐年 +7000/+7000/+110000/+55500/+5000/0/+31000/+35000/0，另有 12 个尝试全部 0 元。结论：只有"接单/建站/接口对接"真正赚到钱，平台流量变现几乎全军覆没。

关于本站

本站是静态站点，托管在 GitHub Pages，零成本运行。只做一件事：把散落各处的"真实赚到钱"的案例按证据等级整理出来。

不卖课、不做社群、不承诺收益、不推荐任何具体项目。这里只有证据和结构分析。
